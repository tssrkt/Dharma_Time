# Dharma Time (frontend)

Dharma Time - это календарь духовных и астрономических событий: буддийские праздники, индуистские даты, христианские календари, фазы Луны, затмения, метеорные потоки и другие небесные явления. Здесь находится фронтенд веб-версии календаря Dharma Time, который также реализован как Телеграм-бот.
